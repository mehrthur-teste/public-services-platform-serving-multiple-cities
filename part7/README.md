# Part 7 – Compare Contemporary Data Processing Paradigms

[Read the eight-paradigm comparison and explanation](part7-section.md).

The comparison covers relational, spatial, document/semi-structured, multimedia,
time-series, rule-based, analytical and streaming/event-based paradigms. For each
it explains the model, platform sources, suitable/unsuitable workloads and the
recommendation for the final design. The explanation contains 478 words.

Streaming uses the queue/workers already proposed in Part 2. Apache Kafka is cited
as an example explaining event streaming; a specific broker is not selected or
claimed to be deployed. All sources are consolidated in the Word References.
This section requires no new scripts or executed benchmark results.
